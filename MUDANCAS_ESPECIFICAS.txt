2. ARQUIVO: tone_gen.vhd
   ═══════════════════════════════════════════════════════════════════════════
   
   LOCAL: Processo sequencial (IF ativo = '0')
   ───────────────────────────────────────────────────────────────
   
   ANTES:
   ```vhd
   IF ativo = '0' THEN
       contador <= (OTHERS => '0');
       s_audio  <= '0';
   ELSIF contador = UNSIGNED(divisor) - 1 THEN
       contador <= (OTHERS => '0');
       s_audio  <= NOT s_audio;
   ELSE
       contador <= contador + 1;
   END IF;
   ```
   
   DEPOIS:
   ```vhd
   IF ativo = '0' THEN
       contador <= (OTHERS => '0');
       s_audio  <= '0';
   -- Verifica se divisor eh maior que zero (evita divisao por zero)
   ELSIF divisor = (divisor'RANGE => '0') THEN
       -- Se divisor = 0, nao gera tom
       contador <= (OTHERS => '0');
       s_audio  <= '0';
   ELSIF contador = UNSIGNED(divisor) - 1 THEN
       contador <= (OTHERS => '0');
       s_audio  <= NOT s_audio;
   ELSE
       contador <= contador + 1;
   END IF;
   ```
   
   EXPLICAÇÃO:
   • Novo IF verifica: divisor = (divisor'RANGE => '0')
   • Equivalente a: divisor = "00000000000000000" (17 bits zeros)
   • Se verdadeiro: contador e s_audio são zerados
   • Impede que contador nunca atinja "divisor - 1" quando divisor = 0
   • Audio fica em '0' quando nenhum botão está pressionado


3. ARQUIVO: debounce.vhd (NOVO)
   ═══════════════════════════════════════════════════════════════════════════
   
   Este é um novo arquivo completo. Veja debounce.vhd para conteúdo completo.
   
   Resumo da lógica:
   ─────────────────
   • Para cada bit 0 a 7:
     - Se entrada[i] ≠ saida_int[i]: incrementa contador[i]
     - Se contador[i] >= CONTADOR_MAX: atualiza saida_int[i]
     - Se entrada[i] = saida_int[i]: reseta contador[i]
   
   • CONTADOR_MAX = (CLK_FREQ / 1000) × DEBOUNCE_MS
     Com CLK_FREQ = 50MHz e DEBOUNCE_MS = 20ms:
     CONTADOR_MAX = 1,000,000 ciclos de clock

================================================================================
IMPACTO DE MEMÓRIA / ÁREA
================================================================================

Debounce:
  • Componentes: 8x contadores de 32 bits + mux + lógica de controle
  • Área estimada: ~200-300 LUTs (Altera Cyclone V)
  • Memória: ~256 bits (8 contadores × 32 bits)
  • Latência: 20ms (configurável)
  • Performance: Nenhuma limitação, roda a 50MHz

Mudanças em piano_top:
  • Apenas adição de componente e sinal
  • Sem impacto em área
  • Latência total: 20ms antes de dados chegarem ao resto do sistema

Mudanças em tone_gen:
  • 2 multiplexadores a mais
  • ~5-10 LUTs adicionais
  • Nenhum impacto em performance

TOTAL: Pequeno impacto de área (~250-350 LUTs), largamente compensado pela 
funcionalidade corrigida.
