FASE 7: TROUBLESHOOTING (Se necessário)
═════════════════════════════════════════════════════════════════════════════

Problema: Compilação falha com "Component debounce not found"
├─ Causa: debounce.vhd não está no projeto
├─ Solução: Project → Add Files → debounce.vhd
└─ Verificar: Debounce está listado em Files window

Problema: Delay entre pressionar botão e som (>100ms)
├─ Causa: DEBOUNCE_MS muito alto
├─ Solução: Em piano_top.vhd, reduza DEBOUNCE_MS (de 20 para 10)
└─ Recompile em Quartus

Problema: Comportamento ainda errático
├─ Causa: Possível bounce muito longo nos botões
├─ Solução: Em piano_top.vhd, aumente DEBOUNCE_MS (de 20 para 50)
└─ Recompile em Quartus

Problema: Audio não para ao soltar botão
├─ Causa: tone_gen.vhd não foi atualizado com a correção
├─ Solução: Verificar linha com "ELSIF divisor = (divisor'RANGE => '0')"
└─ Recompile em Quartus

Problema: Simulação tem WARNING sobre sinais
├─ Causa: Sinais não utilizados (não é erro)
├─ Solução: Ignorar, compilação está OK
└─ Se quiser: Remover sinais não utilizados (opcional)

Problema: Hardware carrega mas não funciona
├─ Causa: Possível arquivo .sof desatualizado
├─ Solução: Project → Clean → Recompile → Reprogram FPGA
└─ Aguarde: "Full configuration successful"

NOTAS IMPORTANTES
═════════════════════════════════════════════════════════════════════════════

1. DEBOUNCE_MS = 20 é recomendado para switches mecânicos normais
   • Se ainda tiver bounce: aumentar para 30-50ms
   • Se muito lento: reduzir para 10-15ms
   • Testar empiricamente

2. Frequências de som podem estar 2x ao esperado em simulação
   • Motivo: Testbench usa 100MHz, código assumia 50MHz
   • Isso é OK - a lógica está correta
   • Em FPGA real (50MHz) frequências estão corretas

3. Latência total do sistema:
   • Debounce: ~20ms
   • FSM transição: ~1 ciclo de clock = ~20ns
   • Key decoder: combinatorial = ~5ns
   • Total: ~20ms (aceitável para aplicação)

4. Se mudar DEBOUNCE_MS:
   • Recompilar em Quartus
   • Não precisa recompilar em ModelSim (generics)

   • ANALISE_CORRECOES.txt - análise detalhada
   • DIAGRAMA_ARQUITETURA.txt - diagramas
